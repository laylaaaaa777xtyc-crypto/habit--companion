# 🌟 习惯伙伴 — AI分身习惯打卡 App

5个AI角色伴你养成好习惯，治愈可爱风格，全栈可运行。

## 快速启动

```bash
cd habit-companion
npm install
npm start
# 访问 http://localhost:3000
```

## 5位AI分身

| 角色 | 个性 | 口头禅 |
|------|------|--------|
| 🐱 学者猫 | 理性分析派 | 根据计划分析…… |
| 🐶 勇者犬 | 行动力派 | 冲啊！今天也要战胜拖延！ |
| 🦌 精灵鹿 | 温柔治愈派 | 慢慢来，你已经很棒了 |
| 🐉 机械龙 | 效率数据派 | 效率提升X%，继续保持 |
| 👻 小幽灵 | 轻松随意派 | 今天不想动？那就休息一下呗～ |

## 功能

- 注册/登录（JWT，7天有效）
- 性格测试（6题匹配最适合的AI伙伴）
- 习惯打卡（支持每天/每周N次）
- XP经验值系统（Lv.1~10，连续7天额外奖励）
- AI角色聊天（本地规则库，每角色30+条回复）
- 7天打卡图表
- 数据重置

## 环境变量

```
PORT=3000              # 默认3000
JWT_SECRET=your_secret # 生产环境务必设置
```

## 技术栈

- 后端：Node.js + Express + better-sqlite3 + bcryptjs + jsonwebtoken
- 前端：原生 HTML/CSS/JS，无需打包
- 数据库：SQLite（自动创建 habit.db）
